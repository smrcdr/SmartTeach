Проект SmartTeach

Это сервис для взаимодействия учеников и преподавателей, а также создания курсов.

Любой пользователь может присоединиться к группе, а также создать новую.

Группа - это пользователи, из которых есть администраторы группы, а остальное - просто пользователи. Администраторы группы могут настраивать её, добавляя различные функции(или убирая)

Класс - быстрая настройка для группы, которая из простой группы(например для курсов) делает учебную группу с уроками, домашними заданиями, расписанием и т.д. 
Эти настройки по отдельности можно выставить самостоятельно и в обычной группе, но класс автоматически из выбирает, чтобы не настраивать самостоятельно группу.

Роли: 
Тут нет глобальных ролей. При регистрации - все просто USER. Исключение - ADMIN и MODERATOR - это администрация сервиса. Но внутри групп есть разделение - OWNER, ADMIN, USER

Стек:
Бэк: Nest + TS + Zod + Prisma
Фронт: TS + Vue
СУБД: PostgreSQL
Авторизация: JWT
Хранение фотографий и файлов: MinIO
Формат API: REST + WebSocket для чатов

Страницы пока не описывай, но пункт напиши и напиши что пока страницы не описаны

Уточнение - всё строится вокруг групп. Даже курс - это группа, в которой просто можно выключить совместные чаты и т.д. Администраторы/владелец курса создает уроки, прикрепляет их к курсу - вот так и получается
