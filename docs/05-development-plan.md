# 5. Текущее состояние реализации

Исходный календарный план из этого файла устарел. Вместо него здесь зафиксировано текущее состояние проекта по репозиторию.

## Backend

В `apps/api` уже реализованы:

- системный health-check
- авторизация и сессии
- профиль пользователя
- файлы
- группы и настройки групп
- участники групп и заявки на вступление
- полезные ссылки группы
- материалы, подсекции и уроки
- задания, сдачи и проверка сдач
- расписание
- групповые и личные чаты

Для backend есть:

- Prisma schema
- миграции и seed
- Swagger-документация
- ручной smoke-сценарий в `docs/backend-smoke-test.md`

## Frontend

В `apps/web` реализованы:

- публичные страницы платформы
- авторизация и регистрация
- каталог групп
- мои группы
- создание и вступление в группу
- превью группы
- рабочее пространство группы
- профиль и редактирование профиля
- общий раздел чатов

Внутри рабочей области группы есть отдельные страницы для:

- обзора группы
- материалов и уроков
- заданий и сдач
- участников
- расписания
- групповых чатов
- заявок на вступление
- настроек группы

## Документация и контракты

Актуальные технические источники:

- `docs/openapi.yml` для REST API
- `apps/api/prisma/schema.prisma` для схемы данных
- `apps/web/src/app/router/routes.ts` для карты экранов

## Что в этом файле больше не хранится

Этот файл больше не используется как roadmap с датами. Если появится новый план работ, его лучше вести отдельно от базовой архитектурной документации, чтобы не смешивать фактическое состояние проекта и временные оценки.
