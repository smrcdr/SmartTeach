Документ по проектированию веб-сервиса "Вупсень & Пупсень: ГусениСоц"
1. Введение
   Название: Вупсень & Пупсень: ГусениСоц
   Описание: Социальная сеть для гусениц, в которой они могут выкладывать фотки, комментировать посты и голосовать за лучшую гусеницу месяца.
   Целевая аудитория: Гусеницы, их друзья и потенциальные будущие бабочки.
2. Анализ требований
   Функциональные требования
   Регистрация и вход (логин, пароль, имя пользователя).
   Создание постов (текст + изображение).
   Лайки и комментарии к постам.
   Голосование за гусеницу месяца.
   Нефункциональные требования
   Должно работать на мобильных и десктопных устройствах.
   Сервер должен выдерживать 100 пользователей одновременно.
   Простой и дружелюбный интерфейс.
3. Концепция пользовательского интерфейса (UI/UX)
   Основные страницы:
   Главная страница (лента постов).
   Профиль пользователя (аватарка, список постов, кнопка "эволюционировать").
   Страница голосования за лучшую гусеницу месяца.
   Пользовательские сценарии:
   Вупсень заходит на сайт, регистрируется, загружает фотку с листьями, получает лайки от Пупсеня.
   Пупсень находит пост Вупсеня, комментирует его ("Ты точно станешь бабочкой!").
   Другие гусеницы голосуют за Вупсеня как за лучшую гусеницу месяца.
4. Архитектура системы
   Технологии:
   Frontend: Vue.js (для динамичного интерфейса).
   Backend: Flask (обрабатывает запросы, хранит данные).
   База данных: PostgreSQL (хранит пользователей, посты, лайки).
   Структура базы данных:
   Users (id, username, password_hash, avatar).
   Posts (id, user_id, text, image_url, timestamp).
   Likes (id, post_id, user_id).
   Comments (id, post_id, user_id, text, timestamp).
   API (основные запросы):
   POST /register – регистрация пользователя.
   POST /login – вход в систему.
   GET /posts – получение списка постов.
   POST /posts – создание нового поста.
   POST /likes – лайк поста.
   POST /comments – добавление комментария.
5. План разработки
   Неделя 1: Дизайн интерфейса (мокапы, цвета, логотип "ГусениСоц").
   Неделя 2: Разработка backend (база данных, API для постов и лайков).
   Неделя 3: Разработка frontend (страницы, формы, отображение постов).
   Неделя 4: Тестирование, исправление багов, деплой на сервер.
6. Итоговые выводы и перспективы
   Базовая версия позволит гусеницам общаться, делиться фотографиями и голосовать за лучших.
   В будущем можно добавить систему достижений (например, "Гусеница-блогер месяца").
   Можно ввести анимацию превращения в бабочку, когда гусеница набирает 1000 лайков.
