# 1. Введение

**Название:** SmartTeach

**Краткое описание:** SmartTeach - это учебная веб-платформа, построенная вокруг групп. Пользователь может создать группу, вступить в существующую группу по открытому доступу, по коду или через заявку, а затем работать внутри общего пространства группы.

## Что есть в проекте сейчас

Проект реализован как `npm workspace` монорепозиторий:

- `apps/web` - клиентское приложение на `Vue 3`
- `apps/api` - backend API на `NestJS`
- `packages/shared` - общие пакеты для workspace

## Основные возможности

- регистрация, вход, выход и восстановление сессии через `refresh token`
- профиль пользователя и страница другого пользователя
- каталог групп, мои группы, создание группы и вступление в группу
- рабочее пространство группы с разделами:
  - обзор
  - материалы и уроки
  - задания и сдачи
  - расписание
  - участники
  - групповые чаты
  - заявки на вступление
  - настройки группы
- личные чаты между пользователями
- загрузка файлов для аватаров, учебных материалов, заданий, сдач и сообщений

## Модель предметной области

Основная сущность системы - группа. Отдельных режимов `класс` или `курс` в схеме данных и маршрутах нет. Нужное поведение группы настраивается через:

- режим доступа `OPEN`, `BY_REQUEST`, `CLOSED`
- статус группы
- флаги включения модулей в `group_settings`

## Целевая аудитория

- владельцы и администраторы учебных групп
- преподаватели
- ученики и другие участники группового учебного процесса
