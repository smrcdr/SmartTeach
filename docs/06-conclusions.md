# 6. Итоговые выводы

SmartTeach в текущем репозитории - это уже не концепт и не пустой каркас, а рабочее монорепо с отдельными frontend и backend приложениями.

Система построена вокруг группы как центральной сущности. Через нее объединяются:

- участники и роли
- учебные материалы и уроки
- задания и сдачи
- расписание
- полезные ссылки
- групповые чаты

Ключевая практическая особенность проекта - отсутствие искусственно выделенных режимов `класс` и `курс`. Вместо этого поведение группы задается настройками и включенными модулями.

Для текущего состояния проекта основными техническими источниками следует считать:

- `docs/openapi.yml`
- `apps/api/prisma/schema.prisma`
- `apps/web/src/app/router/routes.ts`

Именно они описывают актуальный API, схему данных и карту клиентских экранов.
